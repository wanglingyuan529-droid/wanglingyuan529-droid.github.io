## 今天学了什么

- JDK / JRE / JVM 的关系：JVM 是运行时，JRE = JVM + 类库，JDK = JRE + 编译器 `javac`。
- 基本类型八种：`byte short int long float double char boolean`，以及它们各自的包装类。
- `var` 只是局部变量类型推断，不是动态类型；声明之后类型就固定了。
- 编译与运行是两步：`javac Hello.java` 出 `.class`，`java Hello` 才跑。

```java
public class Hello {
    public static void main(String[] args) {
        int a = 3;
        int b = 4;
        System.out.println(a + b);
    }
}
```

## 卡在哪

1. `pubilc` 拼错时，报错信息里根本不会直接说"你拼错了"，只给一个奇怪的语法错误位置。教训：**先看行号，再看是不是关键字拼错**。
2. `String` 是大写类，不是基本类型；`==` 比引用、`.equals()` 比内容，这一点今天反复写错。

## 用自己的话复述

Java 先编译成字节码再交给 JVM 执行。所以同一份 `.class` 在 Windows 和 Linux 上都能跑——
它不直接面向操作系统，而是面向 JVM。
