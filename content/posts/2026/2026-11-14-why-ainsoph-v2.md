## 旧站的问题

旧版 AinSoph 是九个手写 HTML 文件：一个大厅、四个板块、四张图标。
好看的部分是那棵会生长的树，麻烦的部分是——**所有笔记都写在浏览器的 localStorage 里**。

这意味着：

- 换一台电脑，全部内容消失；
- 清一次浏览器缓存，全部内容消失；
- 把链接发给别人，别人打开看到的是一个空站；
- 搜索引擎永远读不到任何一篇。

它不是"不漂亮"，它只是还不是一个能长期写下去的东西。

## 这次改了什么

内容搬到 Markdown 文件，放在仓库里，由 Astro 构建成静态站，push 之后 GitHub Pages 自动更新。
对我来说，每天的操作只剩三步：

```bash
# 1. 新建当天笔记
pnpm new:note

# 2. 写

# 3. 发布
git add content/ && git commit -m "note: 今天学到的东西" && git push
```

## 树还在

那棵树是旧站里唯一不该丢的东西。新版把它从"铺满全屏的背景"改成首页右侧的一幅画框：
鼠标移进去它才开始生长，长完就停，不再整夜耗电。

叶子会随着文章数量变密——**每写十篇，树就长出一点**。这是我想让记录这件事看得见的方式。

> 慢慢记录，也慢慢发现。
